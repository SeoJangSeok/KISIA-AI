# 랜섬웨어 정적 판별 (EMBER + LightGBM)

Windows 실행 파일을 실행하지 않고 구조만 분석해 랜섬웨어 여부를 판정하는 모델과 웹 앱입니다.
EMBER 특징 추출기로 PE 파일을 2,381차원 벡터로 바꾸고, LightGBM 이진 분류기로 판정합니다.


> **주의**
> - 이 저장소에는 랜섬웨어 샘플이 들어 있지 않습니다.
> - 정적 분석만 하므로 "정상" 판정이 파일의 안전을 보장하지 않습니다.
> - 연구·학습 목적의 결과물이며 백신을 대체하지 않습니다.

## 웹 앱 실행

Python 3.10이 필요합니다. 패키지 버전이 맞지 않으면 실행되지 않으므로 별도 환경을 만들어 설치합니다.

```bash
git clone https://github.com/SeoJangSeok/KISIA-AI.git
cd KISIA-AI

python3.10 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python app/app.py
```

브라우저에서 http://127.0.0.1:5050 을 열고 파일을 끌어다 놓으면 판정과 파일 정보가 표시됩니다.

- 업로드한 파일은 바이트로 읽기만 하며 실행하지 않습니다.
- 서버는 `127.0.0.1`에 묶여 있어 실행한 컴퓨터에서만 접속할 수 있습니다.
- 최대 200MB까지 올릴 수 있습니다.

### 판정 결과

| 결과 | 의미 |
|---|---|
| 랜섬웨어 의심 | 모델 점수가 판정 기준 이상 |
| 정상으로 판정 | 모델 점수가 판정 기준 미만 |
| 지원 범위 밖 | 모델이 학습하지 않은 유형이라 판정하지 않음 |

모델은 **32비트 GUI/콘솔 EXE**만 학습했습니다. 64비트 파일, DLL, PE가 아닌 파일은 "지원 범위 밖"으로 표시합니다.

## 데이터

| | 개수 | 출처 |
|---|---|---|
| 랜섬웨어 (label 1) | 35,392 | 교육과정 멘토 기업에서 제공받은 샘플 (비공개) |
| 정상 (label 0) | 212,978 | 공개 EMBER 2018 데이터셋 |

- 랜섬웨어 샘플은 모두 32비트 EXE입니다. 정상 데이터도 EMBER 2018의 정상 레코드 중 같은 유형(32비트 GUI/콘솔 EXE)만 골랐습니다. 파일 형식의 차이를 랜섬웨어의 특징으로 잘못 배우는 것을 막기 위해서입니다.
- 랜섬웨어는 샘플 파일에서 직접 특징을 추출했고, 정상 데이터는 EMBER가 공개한 원시 특징을 사용했습니다.
- 샘플과 학습 데이터는 이 저장소에 포함하지 않았습니다. EMBER 2018 데이터셋은 [elastic/ember](https://github.com/elastic/ember) 저장소의 안내에 따라 받을 수 있습니다.

## 특징 추출

`PEFeatureExtractor(feature_version=2)`는 두 단계로 동작합니다.

1. `raw_features(bytes)`: 파일에서 9개 그룹의 원시 특징을 뽑습니다.
2. `process_raw_features(raw)`: 고정 길이 벡터로 바꿉니다.

| 그룹 | 차원 | 내용 |
|---|---|---|
| histogram | 256 | 바이트값 분포 |
| byteentropy | 256 | 엔트로피와 바이트값의 결합 분포 |
| strings | 104 | 문자열 개수와 문자 분포 |
| general | 10 | 파일 크기, import·export 개수 등 |
| header | 62 | COFF·옵션 헤더 |
| section | 255 | 섹션 이름, 크기, 엔트로피 |
| imports | 1,280 | 가져온 DLL과 함수 |
| exports | 128 | 내보낸 함수 |
| datadirectories | 30 | 데이터 디렉터리의 크기와 주소 |

## 학습과 평가

### 시간순 분할

데이터를 무작위로 섞지 않고 시간순으로 나눴습니다. 배포된 탐지 모델은 항상 학습 이후에 만들어진 파일을 판정하므로, 과거로 학습하고 미래로 시험해야 실제 성능에 가까운 값을 얻을 수 있습니다.

| 묶음 | 랜섬웨어 (수집 시점) | 정상 (최초 등장 시점) | 역할 |
|---|---|---|---|
| 학습 | ~2023-05, 25,717개 | ~2018-08, 112,494개 | 모델 학습 |
| 검증 | 2023-06, 4,041개 | 2018-09~10, 33,129개 | 조기 종료와 임계값 결정 |
| 시험 | 2023-07~08, 5,634개 | 2018-11~12, 67,355개 | 최종 성능 측정 |

같은 설정으로 분할 방식만 바꿨을 때의 시험 결과입니다. 무작위 분할은 같은 계열의 파일이 학습과 시험에 함께 들어가 성능이 실제보다 높게 측정됩니다.

| 시험 지표 | 무작위 분할 | 시간순 분할 |
|---|---|---|
| AUC | 0.9994 | 0.9987 |
| 오탐율 (임계값 0.5) | 0.009% | 2.41% |

### 평가 지표

"오탐율 0.1% 이하에서의 탐지율"을 기준으로 삼았습니다.

- 사용자 PC의 파일은 대부분 정상이므로, 오탐율이 조금만 높아도 경고가 넘쳐 도구를 쓸 수 없게 됩니다. 그래서 오탐율 상한을 먼저 정하고 그 안에서의 탐지율을 봅니다.
- 정확도는 클래스 비율에 좌우되어 기준에서 제외했습니다.
- AUC는 보조 지표로만 사용했습니다. 위 표처럼 AUC가 거의 같아도 오탐율은 크게 다를 수 있습니다.

임계값은 시험 데이터를 보지 않고 검증 데이터에서 오탐율 0.1%가 되는 지점(0.9468)으로 정한 뒤, 시험 데이터에는 적용만 했습니다.

### 결과

| 시험 데이터 | 탐지율 | 오탐율 |
|---|---|---|
| 검증에서 정한 임계값 0.9468 | 96.47% (5,634개 중 199개 놓침) | 0.27% (67,355개 중 183개 오탐) |
| 임계값 0.5 (참고) | 98.65% | 2.41% |

시험 AUC는 0.9987입니다.

## 한계

- **임계값은 시간이 지나면 어긋납니다.** 검증 데이터에서 0.09%로 맞춘 오탐율이 시험 데이터에서는 0.27%가 되었습니다.
- **시간이 지날수록 탐지율이 떨어집니다.** 시험 랜섬웨어의 수집 월별 탐지율이 2023-07 97.6%, 2023-08 90.2%였습니다. 운영한다면 주기적인 재학습이 필요합니다.
- **두 클래스의 출처와 시기가 다릅니다.** 랜섬웨어는 2022~23년에 수집한 샘플이고 정상 데이터는 2018년 이전에 등장한 파일이라, 모델이 랜섬웨어의 특징이 아닌 출처의 차이를 일부 학습했을 수 있습니다.
- **32비트 EXE만 지원합니다.**
